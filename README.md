## 關於式神工具箱

!個人向非官方網站!

式神收集進度、N 號機黑蛋使用量與技能計算、資源待辦、活動月曆，一頁搞定。

🔗 網頁入口：https://revolcs.github.io/yys_dimsum/

工具使用：Claude（編寫用）；網易《陰陽師》（非商用性輔助用圖示）

## 主要功能

**1. 式神圖鑑**
- 列出所有式神，點一下就可以標記已入手。
- 陸服限定式神預設隱藏，撳一下就可以顯示。

**2. 帳號記錄**
- 分開記錄不同帳號嘅進度，撳「±小號記錄」可以自由新增、刪除或改名。
- 擁有者可以用「☑ 批量修改」一次改多隻式神嘅資料。

**3. 黑蛋地獄**
- 記錄每隻式神嘅黑蛋技能完成情況。

**4. 資源獲取**
- 按每日、每週、每月、一次性等分類列出資源項目，重置時間以 GMT+8 計算。
- 點一下就可以勾選完成進度。

**5. 行事月曆**
- 月曆同七日日程兩種檢視，可以睇到即將結束（3 日內）、進行中、準備上線、永久上線同已結束嘅活動。
- 頁首會顯示下次維護時間、即將結束嘅活動同倒數計時。維護結束時間未定時，首頁會保留原本維護時間並顯示「⚠️維護結束時間未定⚠️」；擁有者可以喺「修改維護時間」入面用「時間未定」開關標記。
- 可以自由切換「月/日」或「日/月」、「12 小時」或「24 小時」顯示，每部機器各自記住；新增活動時，日期欄會提示目前嘅格式。
- 活動可以加上標籤（期間限定、特別加成、課金相關、召喚（抽卡）相關、皮膚上新、長期有效），支援多選同關鍵字自動分類。撳標籤按鈕可以篩選月曆同列表，「全部」掣可以一次過全開或全關；全關時會收埋個別標籤掣，並隱藏所有活動（維護除外）。
- 冇結束日期嘅活動會先自動歸入「長期有效」，頁首會提醒擁有者確認，撳提醒會彈出窗口，可以一次過確定、逐項改或刪，或者先篩出睇。
- 「首次登入起計 N 日」類活動可以設定個人 Day 1。
- 擁有者可以用「📋 貼上台服公告」，將台服公告文字貼入，自動抽出維護時間同各個活動期間。

**6. 免登入版**
- 📦「匯出免登入版」可以將整個頁面下載成單一 HTML 檔案，式神資料同圖片都已經包含喺檔案入面。

## 注意

- 你喺訪客模式嘅點亮紀錄，只會保留喺當前頁面，關閉後會消失。如需保留，可以先撳「匯出」存檔，下次再用「匯入紀錄」接續。
- 呢個頁面係唯讀模式，式神名單、頭像同活動資料會按遊戲最新公告更新。
- 活動同維護時間以台服官方公告為準。
